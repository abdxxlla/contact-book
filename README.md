# 📒 Contact Book

A command-line contact management app built in Python.

## About
This was my first Python project, built to practise core concepts like classes, object-oriented programming, loops, and file handling.

## Features
- Add a contact with name and phone number
- Search for a contact by name or phone number
- Delete a contact
- Display all contacts
- Contacts are saved to a JSON file and persist between sessions

## Concepts Used
- Classes and OOP (`Contact` and `ContactBook` classes)
- Lists and dictionaries
- Loops and conditionals
- Input validation
- File handling with JSON
- f-strings and list comprehensions

## How to Run

1. Make sure you have Python installed
2. Clone this repository
```
git clone https://github.com/yourusername/contact-book.git
```
3. Navigate to the project folder
```
cd contact-book
```
4. Run the program
```
python main.py
```

## How to Use
When you run the program, a menu will appear:
```
1. Add Contact
2. Search Contact
3. Delete Contact
4. Display Contacts
5. Quit
```
Enter the number of the option you want and follow the prompts.
